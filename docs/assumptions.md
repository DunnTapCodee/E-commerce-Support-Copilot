# Project Assumptions Register (v1)

> **Purpose:** Track critical unverified assumptions across product, architecture, ML, security, and operations so coding agents do not silently treat them as facts.
> **Linked Documents:** [Requirements Baseline v1](product/requirements.md), [Architecture Overview v1](architecture/overview.md), [REPO_GUIDE.md](agent/REPO_GUIDE.md)

| ID | Assumption | Current Evidence (`Observed`) | Impact If Wrong | Verification Plan | Status | Priority |
| --- | --- | --- | --- | --- | --- | --- |
| `ASM-001` | **CKEY.VN (`https://api.xah.io/v1`) presents a valid public CA TLS certificate chain.** | `verify=True` is now enabled by default (`contracts/llm_failover.py`, `llm_classifier.py`, `generator.py`, `copilot_draft_engine.py`); unit tests mock HTTP only. | All live LLM calls to CKEY.VN will fail with `SSLCertVerificationError` until `LLM_CA_BUNDLE` is configured (falling back to ML/template/escalation). | Run an authorized online TLS handshake check against `https://api.xah.io/v1` (without `verify=False`); if custom CA is needed, supply `LLM_CA_BUNDLE` in `.env`. | `Unverified` | **High** |
| `ASM-002` | **Local ML fallback quality is acceptable using existing legacy artifacts until Module 1 is deployed.** | `artifacts/models/intent/` contains only `.gitkeep`. `IntentPredictor._load_legacy_model()` loads legacy sklearn `1.6.1` pickle (`ML-model/` / `intent_model.pkl`) under runtime sklearn `1.9.1` (emitting `InconsistentVersionWarning`); `test_robustness.py` shows low confidence on unaccented Vietnamese (`"doi tra hang trong bao lau"` < `0.60`). | During a CKEY.VN outage, fallback accuracy on Vietnamese/colloquial queries may degrade sharply or trigger high escalation rates; sklearn version drift could break unpickling in another environment. | Train and deploy real Module 1 artifacts into `artifacts/models/intent/` matching serving library versions, and evaluate on `data/eval/real_vi_handwritten.csv` + `evaluation/run_release_gates.py`. | `Unverified` | **High** |
| `ASM-003` | **Legacy naive timestamps in `copilot_telemetry.sqlite3` are UTC while legacy naive rows in `copilot_conversations.sqlite3` and `policy_audit_logs.json` are local/shifted wall-clock.** | `telemetry_service/src/database.py` used `DEFAULT CURRENT_TIMESTAMP` (SQLite UTC); `sqlite_state_store.py` and `policy_manager.py` previously wrote `(datetime.now() + timedelta(hours=12)).strftime(...)`. | Historical telemetry charts or cross-table incident timelines could still show a 7h or 12h offset for pre-fix rows. | Inspect sample historical rows in local SQLite/JSON files before any analytics/reporting release; decide in `OD-008` whether a one-time historical migration script is needed. | `Partially Verified` (code verified; live DB rows not audited) | **Medium** |
| `ASM-004` | **Single-node SQLite (WAL mode) is sufficient for current scale.** | `copilot_telemetry.sqlite3` and `copilot_conversations.sqlite3` run on local disk / Docker volume `copilot_data` with `PRAGMA journal_mode=WAL;`. | Multi-replica or high-concurrency deployments will hit SQLite write lock contention (`database is locked`) and split-brain state across containers. | Load-test concurrent `/chat` + `/audit/log` writes if deploying beyond single-host demo/dev; plan PostgreSQL/Redis migration if multi-instance scaling is required. | `Unverified` | **Medium** |
| `ASM-005` | **Current guardrail thresholds (`0.60` confidence, `0.70` faithfulness, `FINANCIAL_INTENTS`, regex rules) match business risk tolerance.** | Implemented in `services/gateway/src/guardrails.py` and `services/conversation_service/src/policies/response_dispatcher.py`; `conversation_service` uses `0.50` for `is_in_scope` and does not run `evaluate_response_faithfulness`. | Either excessive false escalations (agent overload) or safety leakage (e.g., unhandled financial intent or hallucination in primary path). | Owner review of `SC-001`..`SC-007` and `OD-005` against real CSKH cases. | `Unverified` | **High** |
| `ASM-006` | **Demonstration data (`mock_orders.json`, `policies.json`, seeded staff/customers) contains no real customer PII.** | `README.md` states orders and policy data are demonstration data; however `copilot_telemetry.sqlite3` and `data/continual_learning_dataset.csv` store raw user queries entered during sessions. | If real customer queries/phone numbers are entered during pilot testing, `data/continual_learning_dataset.csv` (tracked in Git) could leak PII. | Audit `data/continual_learning_dataset.csv` before any push and define PII redaction / `.gitignore` rules (`OD-008`). | `Unverified` | **High** |
| `ASM-007` | **Standalone service launches receive `.env` variables from the caller/orchestrator.** | `run_dev.py`, `docker-compose.yml`, `document_service/src/config.py`, and `rag_service/src/generator.py` load `.env`; `gateway`, `conversation_service`, and `intent_service` do not auto-load `.env`. | Running `uvicorn services.intent_service.src.main:app` directly without exporting `.env` will have empty API keys and trigger ML/escalation fallback. | Document startup contract or add explicit `load_dotenv` consistently if standalone launches are part of the supported dev workflow. | `Observed` (verified in code) | **Low** |
